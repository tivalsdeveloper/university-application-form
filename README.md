# University Application Form

A mobile-friendly, four-step university application form designed for GitHub Pages.

## Included

- Applicant and study details
- Household and financial supporter information
- Funding, special circumstances, and residence information
- Full next-of-kin / emergency contact section
- Required-field validation
- Local draft saving in the applicant's browser
- Print / Save as PDF review
- Responsive mobile and desktop layout

## Publish with GitHub Pages

1. Create a public GitHub repository.
2. Upload `index.html`, `styles.css`, and `app.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.

GitHub will show the public website address after deployment.

## Privacy and real submissions

This static version stores drafts only in the user's browser and does not send application data anywhere. Before collecting real personal information, connect the form to a secure authenticated database or university application service, add a privacy notice, restrict staff access, and comply with South Africa's POPIA.
